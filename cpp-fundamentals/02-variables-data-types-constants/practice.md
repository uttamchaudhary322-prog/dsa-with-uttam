# Practice — Variables, Data Types, and Constants

Try these after studying the lesson.

1. Declare an `int` named `age` and initialize it.
2. Declare a `double` named `accountBalance`.
3. Store one letter in a `char` variable using single quotes.
4. Store your name in a `std::string`.
5. Declare a `bool` named `isLearningCpp` and set it to `true`.
6. Create a `const int` named `hoursInDay` with the value `24`.
7. Print all values using `std::cout`.
8. Try reassigning `hoursInDay`. Why does the compiler reject it?

## Challenge

Write a small profile program that stores and prints:
- your name (`std::string`)
- your age (`int`)
- your CGPA (`double`)
- your grade (`char`)
- whether you are learning C++ (`bool`)
